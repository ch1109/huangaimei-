## 本地运行

环境：Node.js 22.22.3、pnpm 10.13.1。

```sh
pnpm install
pnpm dev
```

开发地址默认为 http://127.0.0.1:5173。生产版检查：

```sh
pnpm test
pnpm build
pnpm preview
```

生产预览默认为 http://127.0.0.1:4173。启动预览后执行 `pnpm test:browser`，检查五种宽度、详情返回和焦点、减少动画、20 支视频的开始/跳转/结尾，以及冷缓存 10Mbps、100ms 网络性能。优先复用本机 Chrome；可用 `QA_BROWSER_EXECUTABLE` 指定已有浏览器路径。缺少浏览器时运行 `pnpm exec playwright install chromium`。

取得或替换原视频后，使用已安装的 ffmpeg/ffprobe 执行 `python3 scripts/prepare-media.py`。脚本保留原文件，生成 WebP 封面、兼容 MP4 及首屏无声预览。已生成的 MP4 默认复用；替换原片时先移走对应的衍生 MP4，再重新生成。封面选帧位置可在脚本中调整。

没有真实创作过程材料时不显示过程模块。个人练习不得标为品牌客户；公司提供的 AI 人物不能写成本人拍摄或生成。

本次 20 张浏览封面使用内置 image_gen，依据真实成片帧重新设计。它们属于作品集的封面包装，不能当作原视频拍摄素材或品牌官方广告。替换 `assets/cover-designs/Wxx.png` 后执行 `pnpm prepare:covers`，生成压缩 WebP 并更新封面映射；再执行 `pnpm build`。原视频素材脚本不会覆盖设计封面配置。

## 部署准备

本项目尚未公开发布，未接入统计、后台和付费服务。

1. 确认成片、封面、职责和公开简历；原版 PDF 包含电话，页面虽不展示电话，PDF 仍会包含。
2. 选择能承担视频流量的托管，核对地区、费用和权限。当前视频本地按需加载，首次打开不请求 MP4。
3. 设置正式域名后执行 `SITE_URL=https://你的域名 pnpm build`，生成完整作品分享图地址和 canonical。
4. 上传 `dist`，不上传 `assets/originals`、Downloads 或内部材料。托管必须为未知路径配置 `/index.html` 回退；已提供 Netlify 格式 `_redirects`，其他托管需使用对应配置。
5. `/works/:slug` 已生成静态入口供刷新与分享；无效作品地址仍需回退才能显示站内返回页面。
6. 不同发布位置需同步修改资源路径；当前默认部署到域名根目录。
