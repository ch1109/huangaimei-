# 整站视觉统一：诊断与三个方向

日期：2026-10-18。范围：当前本地作品集的开场、作品、关于、联系区块；保留用户认可的作品排布和全部项目内容，本轮仅提出方案，不修改页面实现。

## 本轮实页截图与诊断

1. 开场：布局清楚，花卉画面与紫色强调色有一致氛围；深色底与下方暖白作品区形成大面积硬切。证据：01-current-opening.png。
2. 作品：左简介、右作品的结构成立；黑色导航与浅色正文分离，章节分别使用紫、绿、棕、蓝灰强调色，整站品牌色不够集中。证据：02-current-works.png。
3. 关于：个人内容与作品页信息层次清楚；背景另换为偏黄灰色，文字又转为绿灰色，与开场紫色语言偏离。证据：03-current-about.png。
4. 联系：视觉重心明确；从浅色经历区重新硬切深色联系区，使滚动产生明显断点。证据：04-current-contact.png。

截图可见部分辅助文字偏小、颜色偏淡；最终方案需要检查实际字号和文本对比度。本轮没有进行完整可访问性审计，也不据截图声明符合任何标准。

## 三个视觉方向

### 曜石影院

- 主底色#17171B，辅助表面#212127，暖白文字#F2F0E9，雾紫强调#C6B2DE。
- 首屏、作品、关于、联系、详情统一深色。用轻微表面亮度差、细线和留白划分章节。
- 导航、播放器、筛选和所有链接采用同一套紫色与暖白状态。作品封面保留原色。
- 衔接：同色底连续滚动，章节编号轻淡入，卡片仅小幅上移；避免大面积变色、闪烁和复杂转场。
- 优点：延续现有开场氛围，影像突出；需要保证长简介在深色底上的阅读舒适度。

### 雾紫影像馆

- 主底色#F0EDF5，辅助表面#E7E1EF，深紫灰文字#2B2633，紫色强调#806396。
- 全站采用浅雾紫，首屏与联系页也取消黑底。自然画面自身保持原色。
- 章节共用浅紫细线、标题、编号和按钮状态；局部柔和光感仅放在留白区域。
- 衔接：统一底色与间距，局部浅紫表面区分层次，图片缓慢显现；正文保持稳定。
- 优点：柔和、有个人辨识度，长文阅读轻松；需要控制紫色面积和饱和度，避免封面与背景争夺注意。

### 暖白胶片志

- 主底色#F4F1E9，辅助表面#EAE6DC，深墨文字#292923，橄榄灰强调#747D65。
- 开场到页尾统一暖白纸感，以同一阅读网格、标题和细线构成摄影手记的节奏。
- 沿用当前作品编排，封面原色与照片形成主要色彩，背景保持克制。
- 衔接：大留白、统一章节横线和编号，悬停仅箭头微移；不使用强烈发光或大块反色。
- 优点：干净耐看，适合完整阅读简介；整体戏剧感比深色方向更克制。

## 共同边界

保留4个作品章节、6个项目模块、20部作品与全部简介。作品网格、原视频、图片、人物照片和播放行为不变。最终实施需统一导航、正文、详情页、页尾、悬停、焦点、选中与播放器状态，并支持减少动态效果。

三个生成图是视觉方向示意，只节选页面内容以便比较整体色彩和章节衔接，不代表删减最终网站内容。
