# 多巴胺透明软糖标签墙｜第二轮视觉与动效

日期：2026-10-14。依据：用户要求颜色更有多巴胺感、材质更高级、造型更可爱、动效更丰富并带来啊哈时刻。本文件替代第一轮视觉规格中的淡色分组、全胶囊造型和仅轻弹的动效方向。内容定稿与 15 个标签、20 支作品的映射继续使用“标签内容.json”。

当前交付为静态视觉稿和动效设计，尚未制作或测试 WebGPU 实现。用户随后要求再增加浅蓝色毛玻璃方案，因此本轮共四张，按在聊天中的实际显示顺序编号，不沿用上一轮编号作为选择依据。

颜色用于视觉节奏，不再硬性以颜色绑定三种标签维度。分组信息依靠内容表、可选分组文字与布局体现，选中状态同时有文字和标记。

材质以带吸收色的半透明软胶为目标：饱满厚度、弧边折射、中心仍有透光层次，柔和的大面积环境高光和有分寸的彩色接触阴影。标签表面保持连续，不把一圈圈白色描边作为高级材质。深色中文始终清晰，文字不参与折射。

造型采用六瓣花、饱满爱心、云团、软四角星、豆豆、四叶形、软蝴蝶结和圆润卵石。各造型中部留足文字宽度，6 个中文字的标签使用云团、豆豆或宽蝴蝶结。尺寸差异服从内容和阅读，不代表技能评分。

## 三个方向的惊喜机制

| 方向 | 页面结构 | 点击时的啊哈动作 |
| --- | --- | --- |
| 软糖花园 | 上方错落标签墙，下方作品与解释 | 标签被捏扁后弹起，带出一段短软胶轨迹，引出作品封面 |
| 果冻传送门 | 左侧标签，右侧作品 | 选中形状的视觉副本伸展为作品窗口边缘，封面从中显现；随后边缘收敛 |
| 软糖星座 | 标签围绕中央作品舞台，底部推荐解释 | 标签向中央传递轻微脉冲，舞台以花瓣般的遮罩打开，作品露出 |
| 冰蓝雾面 | 浅蓝异形标签墙，下方作品与解释 | 点击触发短波纹，作品上方雾面从触点散开，真实封面浮现 |

这四种是可供选择的独立方案。实现只采用选定方向的一种主动作，避免多套揭示动画叠加。

### 新增浅蓝毛玻璃方向

第四张采用冷白 #FAFCFF、冰蓝 #D8ECFA、选择色 #78BFEA 和深蓝灰文字 #263F57。中部雾面微纹理与圆润清透边缘形成材质对比，花朵、云团、爱心、软星和豆豆保留造型变化。图片仍有明显边缘高光；若选择该方向，实施时需以雾面透射与细腻表面粗糙度为重点核对，避免退回普通高光树脂。

选中后约 0–140ms 轻压标签，140–320ms 轮廓回弹并传出很小的蓝色波纹，220–650ms 作品纹理上的模糊遮罩从触发方向退去，500–850ms 文字依次清晰出现。封面最终完整清晰，不长期覆盖雾面。不要求用户擦拭或完成额外手势，点击、触屏和键盘都能触发。

毛玻璃揭示只影响场景内的作品纹理。通过同一纹理的清晰采样与模糊采样加上柔软遮罩混合，形成散雾视觉；静态毛玻璃标签使用实际材质和微表面结构验证。不能以一个粗糙度参数假定完整 UI 散雾效果已经成立。

## 动效编排

首次进入：标签按空间组依次落位，约 700–1000ms 完成，轻微转动并软着陆。最后一次回弹提示可触摸。整面墙落位后保持安定。

靠近：指针进入标签范围后，物体向指针轻微偏移，最大约 4–8px；高光随着角度改变。文字始终在点击目标中清楚可读。最多两个邻近标签响应一次小幅波动，指针离开后约 300ms 归位。键盘聚焦用抬升和清晰轮廓表达同等可操作性。

按压：约 100–140ms 内标签沿受力方向压缩约 10%–14%，横向膨胀约 4%–6%；松开后阻尼回弹。形变需控制在自身预留空间，保持相邻入口可点。

首次真正选择的完整揭示约 850–1000ms，后续选择缩短至约 350–500ms。内容和 aria-pressed 立即响应用户操作，视觉动画不作为数据更新的前置条件。

| 时间（初值） | 视觉事件 | 阅读与操作 |
| --- | --- | --- |
| 0–140ms | 被点标签压扁；选中标记出现 | 立即更新当前标签与结果语义 |
| 140–320ms | 标签弹起；最多两个邻居轻颤 | 原按钮位置保持稳定 |
| 220–520ms | 视觉副本朝舞台伸展，或舞台收到色彩脉冲 | 推荐区保留固定占位，避免页面跳动 |
| 400–760ms | 真实作品封面通过柔软遮罩揭示 | 播放按钮持续可用；点击即停止过渡进入播放 |
| 580–900ms | 作品名、推荐理由和职责依次清晰出现 | 正文只做轻微位移与透明度变化 |
| 900–1100ms | 胶质边缘、轨迹和邻居恢复安定 | 阅读时不持续晃动 |

四个方向都要表达同一件事：用户所选的能力带出了对应作品。动画与内容发现有关，不另加无关彩纸、庆祝爆炸或无限背景漂浮。

首次默认作品预先展示，用户不需等待开场动画才可操作。啊哈揭示留给首次主动选标签，不能开场就消耗惊喜。动画可打断；连续点击只保留最后一次的临时物体、遮罩与结果，取消旧回调。

## WebGPU 实施结构

延用一个场景、一个 canvas 与 DOM 标签按钮的组合。网格造型需为连续圆润的三维曲面；选定视觉后建立对应造型库。用顶点形变与阻尼控制实现柔软按压。所有效果先用 WebGPU 方案设计，并针对实际支持情况处理兼容显示，具体材质与性能由开发验证。

原始标签的可访问按钮、排列位置与焦点始终稳定。移动或展开的是无交互的视觉副本，原位置保留对应标签，不让招聘方反复追逐会逃走的按钮。临时轨迹不遮住其他文本。网格、DOM 文字与点击区域使用同一布局和投影数据。

作品揭示使用实际作品封面纹理与遮罩。封面和临时副本进入 3D 场景，正文留在 DOM。若花朵变矩形难以保持良好拓扑，用“原形状淡出、同色圆润框显现、真实封面遮罩打开”的连续过渡实现；不假设任意网格可无缝形变。

背景折射仅处理场景中的光场与背景纹理，不宣称自动折射 canvas 后方的 HTML。材质性能优先在场景中核定；柔软感应主要由轮廓和按压形变建立，避免依赖昂贵色散。

绘制只在进入、指针操作、回弹和揭示期间进行；空闲停帧，离屏暂停。进入视频播放后停止舞台揭示和标签联动。临时图层在结束或打断时及时回收。没有声音播放或自动视频播放要求。

## 手机与减少动态效果

手机标签按阅读顺序换行，不把桌面星座压缩成过小字。点击范围至少 44px，标签造型之间有清楚边界。保留按压与一次较短作品揭示，不依赖悬停或拖动；页面纵向滚动优先。

系统减少动态效果时取消落位、磁吸、形变、邻居联动和传送，仅以短淡入或立即更新展示结果。GPU 无法启动时提供清晰的静态标签和完整作品入口，浏览体验仍成立。

## 动效验收

1. 第一次主动点击有明确的“标签 → 对应作品”的视觉因果，约一秒内完成。
2. 后续切换更短，可以持续浏览，不强迫重复看完整动画。
3. 作品名称、时长、工作属性与标签映射准确，过程不遮挡文字。
4. 动画中可播放、切换和进入详情，连续点击不会留下重复物体或旧结果。
5. 键盘和手机都能直接到达作品；不需要追逐标签或完成小游戏。
6. 阅读时场景安定；离屏没有持续渲染。性能、实际帧率和折射效果在实现后测试。
