# 透明果冻标签墙｜视觉与 WebGPU 规格

日期：2026-10-14。状态：视觉探索与实施规格；尚未实现或测量 WebGPU 场景。

## 共同设计约束

- 替换首页“从一支作品开始”的海报轮播区域。沿用白底、淡紫、深灰正文与现有中文无衬线字体。
- 15 个标签，能力用淡紫，类型用浅蓝，用人方关注用淡桃；标签名称和推荐内容以“标签内容.json”为准。
- 标签是真实有厚度的圆润透明物体，有可见边缘折射、宽而柔和的环境高光、轻微吸收色和接触阴影。保持柔软果冻质感。
- 所有标签文字清晰、不受折射扭曲。固定布局，点选时不洗牌；形变不遮挡相邻文字。
- 作品封面采用真实站内素材。横版封面预览与竖版播放素材分开处理，播放保持原始比例。
- 当前选择音乐节奏，推荐花舞瞬间；状态必须同时由颜色、选中标记与当前标签文字表达。
- 标题“从一个标签，找到一支作品。”，说明“你关注什么？点选标签，看看我如何在作品里完成它。”
- 主按钮“播放作品”，次按钮“查看项目详情”。不用技术名称作为访客操作入口。

## 三种视觉探索结构

以下名称用于生成记录；三张图在聊天中按实际显示顺序编号。

### 果冻陈列墙

1440×1120 的桌面区域视觉稿。居中标题，约 4 行错落胶囊标签，标签墙占上半区。下方横向推荐台：左侧真实花舞瞬间封面，右侧推荐理由与职责；底部两条相关作品文字入口。轻微倾斜，标签之间留白充分。强调材质与读图清楚。

### 能力索引与作品舞台

1440×1120 的桌面区域视觉稿。标题左对齐。左侧约 55% 是标签墙，右侧约 45% 是主推作品封面及摘要。三组标签以间距和小型分组名称区分，仍保持柔软错落布局。当前标签在左侧高亮。强调挑选标签与看作品可以并行进行。

### 三层透明标签架

1440×1120 的桌面区域视觉稿。标签按剪辑能力、内容类型、用人方关注分成三条宽松的横向带；胶囊从正面展示，轻微厚度透视。下方作品与推荐理由左右排版。用分组提高扫描速度，透明度与颜色更克制，近乎无色玻璃果冻。

## WebGPU 实施选择

建议使用 Three.js WebGPURenderer 与 MeshPhysicalNodeMaterial。WebGPURenderer 优先使用 WebGPU，不支持时可使用 WebGL 2 后端；官方文档：[渲染器](https://threejs.org/docs/pages/WebGPURenderer.html)、[物理节点材质](https://threejs.org/docs/pages/MeshPhysicalNodeMaterial.html)。最终材质、形变节点与回退表现都需在实际项目版本中验证。

- 整面墙共用一个透明 canvas、一个场景和一个渲染器；不为每个标签创建独立 GPU 上下文。
- 以圆润胶囊为基础网格，宽度匹配文字与内边距。低幅度顶点形变配合阻尼弹簧表现按压与回弹，不引入无必要的完整软体物理模拟。
- 使用 transmission、thickness、ior、roughness、clearcoat 和吸收色建立材质；环境照明形成宽高光。白底下保留边缘色与阴影，否则透明物体容易不可见。
- 折射只能处理进入 3D 场景/渲染纹理的背景，不宣称能自动折射 canvas 后方的 HTML。必要时只给场景提供简单底色与低对比光场，避免文字进入折射层。
- 中文文字与真正的 button 留在 DOM，aria-pressed 由 React 管理。用同一布局数据驱动网格位置和 DOM 位置；绘制层不拦截普通滚动。DOM 点击/聚焦把交互状态传给对应网格。
- 文本与标签中心按同一投影定位；标签倾斜幅度小，中文字保持正向。禁止网格大幅旋转后文字与点击区域留在原位。
- 公开部署使用 HTTPS；本地使用受支持的本地开发环境。参照 [WebGPU API](https://developer.mozilla.org/en-US/docs/Web/API/WebGPU_API) 的安全上下文与可用性说明。

## 交互参数初值

| 动作 | 初始行为 |
| --- | --- |
| 悬停 | 轻微抬升，宽高光移动，轮廓放大约 2% |
| 按下 | 纵向压缩约 6%，横向轻微膨胀；释放后阻尼回弹 |
| 选中 | 吸收色稍加深，轮廓更明显，出现选中标记 |
| 回弹 | 约 300–450ms；以实际触感调整 |
| 内容切换 | 约 180–250ms 淡入，保持展示区尽量稳定 |
| 无操作 | 保持静止，按需渲染 |
| 页面隐藏/区域离屏 | 暂停渲染与动画 |
| 减少动态效果 | 无形变与抬升，只更新选择与内容 |

不拦截滚轮，不以拖动为必需操作。快速选择以最后一个标签为准，切换作品前停止旧视频。点标签不自动播放视频。详情关闭时恢复当前标签、结果、滚动和焦点。

## 手机与故障回退

- 手机自然换行，标签点击区域至少 44px。作品区紧跟标签墙，正文至少 14px，推荐封面与播放比例分别处理。
- 若 WebGPU 不可用先尝试兼容的 WebGL 2 渲染；两者都失败时保留 HTML 标签按钮与推荐内容，可用已选视觉生成的轻量静态材质图替代绘制层。
- 限制像素比、材质复杂度与色散，移动端优先降低光效成本；具体阈值通过设备测试决定。
- 测试 GPU 初始化失败、上下文丢失、缩放、窗口调整、键盘选择、减少动画和快速切换。
- 性能目标：交互不拖慢滚动，离屏不持续渲染。当前只有设计目标，没有帧率或兼容性实测结论。
