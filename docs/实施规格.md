# 实施规格

以《作品集网站需求文档》及已确认计划为验收依据。白底淡紫、四张悬挂作品吊牌、20 条分类作品、可分享视频详情、关于、简历、邮箱。

React + TypeScript + Vite + React Router + Motion + 普通 CSS，pnpm 10.13.1。吊牌落位、3° 倾斜、±24px 拖动回弹、6px 拖动阈值、独立翻面；手机停用拖动，减少动画即时切换。分类约 240ms，详情约 280ms。

首页进入作品保留背景、分类、位置与焦点；直接访问详情独立显示；下一件替换地址；视频按需加载，关闭立即暂停。真实素材从飞书现有播放入口取得，原始文件保留于 assets/originals，衍生资源置于 public/media。不可取得的素材明确记录，不把缺素材状态视作播放验收通过。

开发交付只在本地运行。公开发布前确认视频、公开简历及托管费用。网页默认不展示电话；原版简历仅供本地核查。
