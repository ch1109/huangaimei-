## 实现与取舍

- 独立的 `CinematicAtmosphere` 固定在首页隔离层的最底部，`pointer-events: none`、`aria-hidden`，不参与布局或辅助技术导航。
- Canvas 2D 将四张一次生成的 256 × 256 柔光纹理沿连续三次曲线变形，叠加出宽光幕和不对称褶光。没有新增依赖、WebGL 上下文、全屏动态模糊、粒子或视频背景。
- 23 / 31 / 47 / 59 / 73 秒的独立连续噪声控制形状、宽度与照明。这些是插值时间尺度，不是循环时长；没有往返关键帧或归零时间轴。
- 桌面绘制缓冲最大宽 1000 像素，目标每秒 60 次绘制，携带时间余量兼容高刷新率。手机和粗指针设备降至每秒 30 次、最大宽 440 像素；实际 390px 视口缓冲为 254 × 549。
- 鼠标最大偏移约 11px / 7px，不同层的响应比例不同；停止移动 180ms 后自然回归。滚动改变光场位置和强度，使用平滑跟随，不分区切换颜色。作品附近的环境响应最高只有 4.5% 透明度。
- 首次进入 2.8 秒柔和显现；减少动态效果仅绘制静态构图，不保留帧循环。页面隐藏、打开作品弹窗时停止循环，恢复时保留艺术时钟。Canvas 不可用时使用现有图片的低亮度静态降级。
- 所有事件均有清理；无每帧 React 状态更新、文档尺寸查询或纹理重建。

2. **连续运行：通过。** 真实页面采样 219 秒，约 59.8 次有效绘制/秒；Canvas 绘制命令平均 0.737ms、P95 1.1ms。高刷新率下相邻绘制间隔的中位数约 14ms、P95 20.9ms。无控制台错误；采样期间未观察到接缝、闪烁或时间轴重置。原始数据见 `desktop-runtime.json`。
3. **时间变化：通过。** 5 秒和 35 秒画面的平均 RGB 通道差约 0.94 / 255，185 秒约 3.51 / 255。变化轻微而真实；三张原始光场和 `light-phases.png` 保留了证据。
4. **原有交互：通过。** 浏览器验证翻卡、花舞作品实际播放（视频 readyState=4、currentTime 持续增长）、弹窗期间光场停止、分类筛选四部个人练习、恢复二十部作品，以及作品目录和返回首页锚点。独立 QA 页也完成了鼠标事件扫动与停止回归检查。

## 可感知性修订（用户反馈后）

用户反馈上一版看不出动态。此前 30 秒画面存在约 0.94 / 255 的通道差，并不足以证明正常浏览时能感受到运动，因此前版的感知性验收判断过于乐观。

本次保留慢速环境光，单独增强丝绸褶光：
- 主要形变时间尺度由 23 / 59 秒改为 8 / 13 / 19 秒的独立连续噪声。
- 将褶光推进到可见边缘，增加曲线控制点的位移幅度和柔光强度。
- 沿光带纵向输送宽幅不规则弯曲，使亮部在光带内部持续流动，而非仅改变整体位置。
- 保持中央、顶部的暗场以及全部布局、卡片和暂停/降级逻辑。

真实页面以每 0.5 秒一帧记录约 12.5 秒，右侧可见光带从竖向变为斜向褶光，左侧独立变化。画面边缘区域的平均 RGB 差为左侧 5.25 / 255、右侧 15.12 / 255；原始截图、时间戳及指标位于 `visibility-revision/`。此记录按实际时间播放，没有加速。
