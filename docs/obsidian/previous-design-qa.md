## 比较历史与修复

1. 首轮 [P1] 后排画框被侧面遮住，画框与提示重叠。调整以画框中心定位，增加前后纵向位移，修正深度缩放。早期截图 `desktop-v1.png` 不作为最终证据。
2. 次轮 [P2] 舞台高、前排画框过厚，底部说明被挤出参考视口。把桌面画框改为约 2.08:1，收紧标题行高与舞台高度；手机保持 16:9。最终截图完整显示操作与说明。
3. [P1] 详情路由使用背景 location，单靠组件 useLocation 无法识别前台弹窗，可能在完整视频播放时重启预览。改为由 App 传递 modal 暂停状态。浏览器复验：弹窗打开后转盘预览元素数为 0，仅详情视频播放；关闭恢复 `orbit-watch` 焦点。
4. 最后调整侧面透视角度与连续深度缩放。最终全幅与局部比较显示无阻挡主入口、画框出界遮挡操作或主次层级错误。

## 五项视觉检查

- 字体：复用官网系统中文无衬线；深色首行与淡紫第二行、中央主标题及小号英文引导与目标一致。保留真实站点导航尺寸，没有在区块中重复导航。
- 间距：标题、六画框舞台、拖动提示、当前作品、主按钮、分页与三步说明顺序一致。桌面首屏能看到完整操作区。手机缩减为 40px 标题和 210px 舞台，当前作品与播放入口清晰可达。
- 颜色：沿用浅灰背景、炭黑主按钮、淡紫高亮和银紫轨道；对比充足，无高饱和背景干扰视频。
- 图像：六部视频均为现有真实素材；商业口播使用既有设计封面，其他使用原片画面。概念图的夕阳、汽车与花朵是生成后的示意，正式实现保留真实作品而非把概念图当视频封面。空轨道使用独立生成的透明 PNG，画框是真实可交互的 DOM 层与 CSS 3D 变换。
- 文案：保留选定标题、拖动提示和主要动作。移除“交互概念图”标识，加入前后切换与暂停预览；三步说明用顺序数字沿用同一淡紫圆形样式。个人练习身份仍在作品分类与详情显示。

## 功能验证

- 鼠标真实拖动：带惯性运动并吸附至最近作品；拖动后仍在首页，没有误开详情。
- 手机尺寸下拖动：从《花舞瞬间》切换至《春日与蝴蝶》；未模拟真实手机硬件触摸，触控按同一 Pointer Events 流程支持 pan-y。
- 前后按钮、指定作品按钮与键盘选择共享状态；单测验证首尾循环、Home/End 和先选片再播放。
- 浏览器预览：readyState=4、paused=false，同一时间只挂载一个静音预览；预览失败保留作品画面。
- 点击完整视频：进入匹配作品详情并播放；关闭回到原位置与入口焦点。
- 暂停预览：预览移除，画面恢复海报；系统减少动态偏好不自动预览，并即时切换。
- 手机与平板均测得 documentElement.scrollWidth <= innerWidth；当前画框、方向按钮与播放按钮无越界。
- 浏览器 error/warn 日志为空。
- `pnpm test`：3 个文件、23 项通过。`pnpm build`：TypeScript 与生产构建通过，20 个原有静态作品分享入口生成成功。

## 接受差异与 P3

- 参考中的图像光色被真实成片替代，默认视频循环时自然变化；这是作品真实性要求。
- 后排画框更收拢；可在后续调整静止姿态中后排的露出量。
- 未添加 WebGL 依赖；使用浏览器 3D 透视与轻量惯性动画实现，轨道为装饰图，视频与操作可独立使用。
- 未进行所有六部原片的完整时长回归，也未在真机 Safari/Android 浏览器验证；完成的是本地浏览器的主流程和响应式验收。
