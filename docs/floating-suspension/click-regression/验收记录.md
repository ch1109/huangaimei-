# 卡片点击翻转回归修复

2026-10-19。本记录取代上一轮仅增强悬停后做出的交互验收结论。

## 问题与修复

此前的鼠标倾斜、缩放、自动轻摆以及双面 180° 翻转共同作用在交互元素的三维层级上。DOM 测试能够直接触发 onClick，因此不能证明实际浏览器的鼠标命中可靠；静态截图也无法检出此问题。

本次调整为固定的原生封面按钮，倾斜、缩放和轻摆只作用于其内部 pointer-events:none 的视觉内容。封面按钮本身在可操作时始终为 transform:none。卡片反面使用独立的平面容器；未展示的一面同时 hidden、inert，不再叠在另一面上参与点击判定。

翻转按“当前面收至 90° → 切换可见面 → 新面展开至 0°”顺序完成。过渡期间锁定重复点击，展开完成后恢复操作与焦点。减少动态设置下立即切面。正面按钮和背面控件保留原 DOM、ID、作品数据与跳转行为，返回后可以反复操作。

## 实际浏览器回归

在独立的内置浏览器标签页检查，使用真实鼠标和键盘操作，没有用 DOM click() 代替鼠标命中：

- 四张卡片每张检查 3×3 共 9 个命中点，总计 36 个点均命中对应封面原生按钮。
- 每张卡片分别完成两轮鼠标“封面翻面 → 背面返回”，共 8 轮，最终四卡均恢复到正面 idle 状态。
- W03 悬停时视觉内容为 1.025 倍及三维倾斜，原生按钮仍为 transform:none，9 个命中点仍正确。鼠标点击箭头后完成翻面。
- W01 的查看详情入口正常打开作品详情，未创建视频；关闭详情后继续操作卡片正常。
- W03 背面鼠标播放进入 `/works/taiying-2026`，原视频 `/media/W03.mp4` 为 paused=false，关闭可回到卡片。
- W03 的 Escape 返回封面通过；W15 的快速双击之后正常到达背面 idle，并可继续返回。
- 390×844 CSS 视口下，W01 正常翻面与返回；横向浏览至 W15（scrollLeft=849px）后也正常翻面与返回。两者背面 clientHeight=scrollHeight=365px，整页无横向溢出。
- `runtime.json` 保存命中点和实际页面状态，`mobile-back.jpg`、`mobile-last-back.jpg` 保存手机宽度的背面状态；最终桌面截图为 `desktop-back.jpg`。

## 自动回归与构建

新增四张卡片各自的行为回归，循环点击封面图片、标题、箭头，检查切面、返回与原生按钮焦点恢复，并核对背面详情和播放的作品 ID 与触发入口。保留原有的独立翻面、Escape、详情关闭、视频停止和挂点坐标测试。

`pnpm test`：5 个测试文件、39 项测试通过。`pnpm build`：类型检查、Vite 生产构建与 20 个分享页面生成通过。第一次构建曾遇到 dist/home 临时文件占用（EPERM），随后原命令重跑通过，没有改动构建配置或删除项目内容。

系统减少动态偏好由自动测试覆盖，未在内置浏览器模拟系统设置；窄屏检查为实际浏览器视口测试，未使用实体手机。
