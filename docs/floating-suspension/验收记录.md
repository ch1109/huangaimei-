## 第二轮：加强线条的视觉重量

根据“线条太细、没有美感”的反馈，调整当前版本：主线由 1px 加粗到 2.2px，吊线由 0.8px 加粗到 1.25px；主线使用有层次的浅紫色渐变，节点直径调整为 4.5px，卡片顶部连接座宽 7px、线宽 1.8px。弧线下垂深度由舞台宽度的 1.2% 增至 2.1%，形成更清晰、舒展的悬挂轮廓，继续保留两端渐隐。

## 初版实现

- 将 `/home/suspension-rig.png` 整体位图替换为 `SuspensionRig.tsx` 的 SVG。旧素材保留，首页不再引用。
- 横线为连续三次贝塞尔曲线，1 CSS px、冷紫灰、46% 不透明度。线段跨越全部四个挂点，两端通过 SVG mask 渐隐。
- 吊线为 0.8 CSS px；主线节点直径 3.1px；卡片顶部只保留 5px 的短连接座，无圆环或金属材质。
- 在卡片实际顶部旋转中心放置零尺寸锚点，以其 DOM 边界测量 SVG 坐标。ResizeObserver 观察舞台、可视容器和四张卡片，同时监听窗口、visualViewport、字体就绪和横向滚动。
- 手机保留项目原有的 1200px 横向卡片舞台。主线的渐隐范围随可视窗口滚动，不在手机屏幕边缘留下硬切线头。
- 主线先渐显，节点及卡片错时淡入。四张卡片使用 13.7 / 17.3 / 15.1 / 19.7 秒周期及不同相位，静态摆幅 -0.22°～0.26°；鼠标倾斜反馈也同步收敛。所有变换围绕顶部连接点进行，因此摆动不需要持续测量或逐帧更新 SVG。
- 鼠标或键盘焦点只提高对应节点的低强度亮度，无光晕。滚出可视区及文档隐藏时暂停摆动。减少动态效果由 CSS 媒体查询和现有 Motion 用户偏好共同处理。
