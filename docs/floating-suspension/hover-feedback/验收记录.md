# 首页卡片悬停反馈

2026-10-19。

本轮验收后仍出现用户可复现的点击回归；最新修复及完整交互回归记录见 `../click-regression/验收记录.md`，以下保留为历史记录，不再作为当前交互可靠性的验收依据。

原实现只在鼠标移动时改变倾斜角，最大 X/Y 倾斜仅为 0.3° / 0.4°，没有独立的悬停进入变化。浏览器实际的减少动态设置为 false，悬停与精确指针媒体查询均为 true，因此主要问题是反馈过弱。

## 本轮调整

- 鼠标进入封面后，从顶部连接点平滑放大至 1.025 倍，退出后回到 1。
- 鼠标跟随的立体倾斜范围为 X ±2.5°、Y ±3.5°；平面 Z 旋转仅 ±0.16°，保留轻盈的悬挂感。
- 根据未变形的 article 测量鼠标相对位置，避免在边缘跟随自身变形而抖动。
- 同步增强磨砂正面、边框、柔和阴影及右下角箭头反馈，不添加发光层。
- 悬停期间暂停该卡片原有的缓慢轻摆，其余卡片继续按独立相位摆动；退出后恢复。
- 翻面时清零倾斜并恢复 1 倍大小，背面按钮保持中性姿态。实际浏览器复查发现，翻面后继续叠加立体倾斜可能让背面控件的命中落到外层容器，因而将立体跟随限定在封面，背面仍保留颜色及边缘反馈。
- 键盘 focus-visible 可获得同等强调。鼠标样式限定在 hover + fine pointer 条件内，触屏不触发鼠标跟随。减少动态设置下关闭缩放、倾斜与过渡，保留非运动的颜色提示。

## 实际浏览器

- 浏览器视口 1930×1244 CSS px，四张卡片正常显示，悬停不自动翻面。
- W11 左上方鼠标定位后，实际 scale=1.025，rotateX=2.23934°，rotateY=-2.81709°，rotateZ=-0.128781°。
- 对应卡片摆动为 paused，其余三张为 running；箭头 scale=1.12，背景与边框随悬停变化。
- 悬停状态下，顶部真实挂点与 SVG 吊线端点误差约 0.000288px，未出现悬空或断线。
- 鼠标移出并移走键盘焦点后，四张卡片 scale=1、transform=none，自动轻摆恢复。
- 鼠标点击 W11 封面可正常翻面；背面中性状态下，播放按钮中心的 elementFromPoint 命中按钮本身。鼠标播放进入 `/works/flowers-in-motion`，原片 `/media/W11.mp4` 为 paused=false；关闭后焦点恢复，Escape 返回封面。
- `hover-active.jpg` 是实际浏览器的交互状态截图，使用右键定位并以 Escape 关闭菜单；图中额外的外轮廓是既有 focus-visible 无障碍焦点框。
- `idle.jpg`、`reset.jpg` 与 `runtime.json` 保存对应状态及测量值。
